# Ignorance

给 Typora 2.0 用的主题：纸面感的中文排版，八套浅深配色。

## 内容

- 八套配色：天蓝、松绿、书卷、石墨、赤陶、深海青、紫藤、琥珀，各有浅色和深色，跟随系统明暗。
- 主题选项（设置 ▸ 视图）：阅读宽度、段落节奏、双猫、标题编号、表格十字高亮、墨水屏。
- 提示块：note、tip、important、warning、caution。
- `::: 名称` 容器：说明类、布局类（kpi、cols、tabs、details、card、chapter、compare）、流程类（timeline、steps、process、roadmap）。
- 目录不用缩进，靠字号、字重和明暗区分层级；嵌套引用和列表同样减少缩进。
- 属性卡、圆角悬浮的侧栏与右侧面板，文件树按文件类型显示不同图标。
- 导出 HTML 同样生效。

## 字体

主题不打包字体，使用系统字体栈：正文用 PingFang SC、Hiragino Sans GB、Microsoft YaHei、Noto Sans CJK SC；标题用 Georgia、Noto Serif SC、Source Han Serif SC、Songti SC。系统没有对应字体时回退到系统默认的无衬线或衬线字体。
